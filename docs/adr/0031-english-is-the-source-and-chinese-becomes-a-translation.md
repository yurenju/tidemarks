# 英文是原文，中文變成譯文

日期：2026-08-21。

## 決定

介面文案改走 i18n，支援 **英文、繁體中文、日文** 三種語言，而且：

> **英文是原文，寫在程式碼裡；繁體中文與日文是譯文，住在 catalog 裡。**

繁體中文原本是原文，這支 ADR 把它降級成三份 catalog 的其中一份。它換到的是**程式碼與註解
全部是英文**，跟 CLAUDE.md〈程式碼用英文，文件用中文〉那條界線終於一致——在這之前，
`packages/app/src/` 底下的檔案是那條規則唯一大面積的例外。

三種語言**地位相同**：少一條譯文，CI 就紅。

## 這件事要付什麼代價

現在的中文文案是手寫的，有語氣：〈書架空的時候〉那句「還沒有書。把 epub 放進來，就從這裡
開始。」不是從英文翻出來的，它本來就是這樣寫的。把英文擺到上游之後，這種句子的產生路徑
變成「先想一句英文，再翻成中文」——而 agent 翻譯的預設行為是貼著原文走。**放著不管，
中文會被磨平。**

擋這件事的有三道，缺一不可：

1. **既有的中文一個字都不重譯。** 搬遷時原樣塞進 `zh-TW.po`，英文是**從中文逆推**出來的，
   不是反過來。
2. **id 是英文原文算出來的。** 所以英文沒動的條目 id 不變，agent 根本碰不到它——「不重譯」
   不是靠自律，是靠機制。
3. **`comment` 是必填的，CI 檢查。** 寫程式的當下是唯一一次「脈絡免費」的時機，事後補是
   用猜的。

第 3 條也是整件事的重點。翻錯最常見的形式不是翻得爛，是**拿另一個地方的詞條來用**：
`Order` 在書架上是名詞（排序方式），在別處可能是動詞；`Publisher's` 的意思是「照書自己的」
而不是「出版社的」；四種螢光的名字是**顏料**（蓼藍、赭石、苔綠、松煙）不是色相。這些差別
從英文字面上一律看不出來，只有 `comment` 講得出來。

## 為什麼不留著中文當原文

留著也做得到多語言——Lingui 不在乎原文是哪一種語言。不留的理由是**程式碼那一半**：

- 中文當原文時，`.tsx` 裡到處是中文字串，而 CLAUDE.md 要求程式碼檔一律英文。那條規則於是
  有一個講不清楚的例外，而例外會擴散——註解裡開始出現「〈排版〉面板」「還沒下載」這種引用，
  因為被引用的東西就是中文。
- 這個 repo 是公開的，讀者不限中文使用者。程式碼是給改它的人看的。

換句話說，中文降級**買的不是多語言，是程式碼的單一語言**。多語言本來哪一邊當原文都做得到。

## 兩個機制上的後果

**「譯文過期」自動塌縮成「譯文缺漏」。** id 由英文算出來，所以改一個字就是換一條詞條：舊的
變孤兒、新的沒有譯文。原本規劃裡的「原文指紋」欄位因此不用做，一個檢查同時擋住兩件事。

**Worker 那半邊是例外，而且非例外不可。** wrangler 用 esbuild 打包 Worker，那條路上沒有
Babel，所以 Lingui 的 macro 在 Worker 碰得到的任何模組裡都會在執行期爆炸。Worker 的訊息
因此**自己取 id**（`email.magicCode.subject`），代價是改了它的英文不會讓譯文失效——動那些
字的時候要順手改另外兩種語言。細節寫在 `worker/i18n.ts` 的檔頭。

這條線是真的線，不是慣例：`SHELF_ORDERS` 因此從 `shelf-order.ts` 搬到
`shelf-order-choices.ts`——Worker 為了 `lastTouchedAt` 匯入前者，而前者一旦有 macro，
production 的 Worker 就打包不起來。

## 界線：介面語言不是書的語言

一個日本讀者用日文介面讀繁體中文書，是完全正常的一件事。**介面語言只決定 Tidemarks 自己
說的話**，書怎麼排、用什麼字型、簡繁怎麼判，全部維持現況，由書自己決定。

CONTEXT.md〈書寫系統〉的 _Avoid_ 早就寫了這條線（「會讓人拿去決定字型或介面語系——那是別的
判斷」），這支 ADR 只是讓它真的有兩件事可以分。

## 一個沒花到的成本：日文字形

三種語言裡只有日文有字形問題——漢字在中日之間長得不一樣（`骨`、`直`、`今`）。原本估計要多
帶一套 JP 字型（16 MB）。

實際量下來不用：Tidemarks 帶的 `Noto Serif CJK TC` 是 pan-CJK build，GSUB 裡掛著
`JAN`／`KOR`／`ZHH`／`ZHS`／`ZHT` 五套 langSys，同一串 `骨今直海` 換 langSys 排版會得到不同
的 glyph（ZHT 是 45053/9799/27756/23386，JAN 是 45051/9797/27755/23385）。瀏覽器切換
`locl` 的依據就是 `lang` 屬性，所以**介面語言是 `ja` 時把 `<html lang>` 設成 `ja` 就對了**，
多花的位元組是零。

同一個機制書那邊本來就在用（`settings.ts` 把 `fontLanguage` 交給 frond），這次只是把它
套到 Tidemarks 自己的字上。

## 這個決定要反悔的話

代價是再做一次同樣規模的搬遷：一百多條文案要從 catalog 搬回程式碼，而且中文那一份要重新
變成唯一的原文。搬得動，但不會有人想做第二次——所以這支 ADR 存在。
