# Scrubber 在直排書鏡射，標頭百分比不鏡射

[Scrubber](../../CONTEXT.md) 以全書百分比為座標。橫式書填色 0%→100% 由左到右；直排（右到左）書則整條**鏡射**——0% 在右、100% 在左、填色由右往左，和翻頁方向一致。我們捨棄了「一律 LTR、實作最單純」的方案，因為直排讀者的空間直覺是右起，非鏡射會讓「往前拉」的方向和翻頁相反。

為避免鏡射後分不清頭尾，兩端加極簡圖示（書首實心／書末空心）＋ 填色永遠從書首端長出；拖拉時預覽泡泡的百分比數字再做二次確認。

標頭的 `%` 讀數維持 LTR 不鏡射：它是抽象的「讀了多少」，不是空間方向。兩者刻意不同步——Scrubber 表達「往哪個方向是書首」，標頭數字表達「進度量」。
