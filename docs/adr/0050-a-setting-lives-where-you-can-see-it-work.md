# 設定住在看得到它生效的地方，形狀跟著值有沒有順序

日期：2026-09-08

〈設定〉是一層樓（`#/settings/...`），跟書架、閱讀器並列。在這個決定之前它有三個 tab：〈排版〉
〈帳號〉〈語言〉，而〈排版〉裡是那六項（主題、欄數、字型、字級、行距、留白），跟閱讀時那個
〈排版〉面板同一個表單元件（[ADR-0005](0005-the-reader-adjusts-their-own-reading-not-this-book.md)）。

問題是那六項裡有五項**在那個畫面上沒有東西可以套用**：它們改的是一本書怎麼排，而那裡沒有書。書架旁邊沒有書，讀者可以把字級從 100% 拉到
160%、把留白從無調到大，畫面上一個像素都不會動。設定改了、也真的存起來了，但要看到結果得先離開
這層樓、打開一本書。那是一個**你按了但看不出有沒有按對**的介面。

同一組控制項在閱讀畫面上完全沒有這個問題：面板從底下升起，上面留著真的書，調什麼都是當場看。

## 決定

### 一、一個設定要出現在哪，看那個畫面能不能顯示它的效果

**五項排版設定離開〈設定〉這層樓**，只留在閱讀時的〈排版〉面板。`#/settings/typography` 這個位址
不再存在，落到預設的 tab 去（現在還沒開放註冊，外面不會有人存著那個網址，見
[ADR-0004](0004-development-phase-and-launch-line.md)）。

**〈主題〉留下來**，因為它是這層樓唯一顯示得出來的那一個：按下「深色」，按的那個畫面自己就換色了。
它跟〈介面語言〉合成一個 tab〈Interface〉，因為兩個都在講 **Tidemarks 自己**長什麼樣、講什麼話，
而不是講一本書怎麼排。tab 從三個變兩個：**Interface** 與 **Account**。

**預設 tab 換成 Account。** 會從書架走進這層樓的人幾乎都是為了登入或自己的書；Interface 那兩列
是設一次就不再回來的東西。

〈主題〉因此有兩個入口（閱讀面板與這層樓），而它仍然是**同一個元件、同一筆設定**
（`ThemeField.tsx`）。ADR-0005 說的「兩邊不是兩份長得像的程式碼」照樣算數，只是現在適用的範圍
從六項縮到一項。

### 二、控制項的形狀，看那組值是「並列的選項」還是「一條刻度」

以前的依據寫在 `docs/design-system.md`，看的是**選項數量與標籤長度**：三四個、每個一兩個字就攤開成
segmented，否則留 `<select>`。那條依據答的是「塞不塞得下」，不是「哪一種控制項講得清楚這件事」。
換成這條：

- **並列的選項**（主題、欄數、字型）：值之間沒有大小關係，一次全部攤在畫面上，而且每一個**畫出
  它自己**：字型的磚用那支字寫 `Aa`，雙欄的磚畫兩欄。這是**磚（tile）**。
- **一條刻度**（行距、留白）：值有順序，讀者問的是「比現在多還是少」。給**stepper**：`−`、目前的
  值、`+`，一列。
- **連續的量**（字級）：滑桿，不變。

磚的圖必須真的在畫那個設定。⚠️ **兩個設定不能用同一張圖**：〈主題〉的「跟隨系統」與〈欄數〉的
「自動」都是「你決定」的意思，第一版兩張都畫成半黑半白的圓，那正是磚會出的錯，而文字格子不會。

**磚的選中是淡底加潮色邊，不是實心潮色**，這是 design-system 那條「選中＝實心」的例外，理由是
面積：一格 segment 只有一個字高，塗滿還是讀成一個字；一塊磚是它的三倍，同樣塗滿就變成一塊色塊，
裡面隱約有張圖。

### 三、版面：標籤在上，全部靠左對齊同一條線

以前是標籤在左、控制項在右，所以**控制項的寬度由標籤剩下多少決定**。實測同一個畫面上兩組
segmented 是 311.6px 與 292.0px，右緣停在不同的地方。混形狀的表單靠的是那一條共同的左緣，不是
靠每個控制項都同一種形狀（Kindle 的面板同時有六種控制項，看起來仍然整齊，靠的就是這件事）。

## 代價

**手機上的〈排版〉面板現在會捲。** 標籤各佔一行、三列變成磚，量到的是：表單 719px、看得到 514px，
**205px 在摺線下**（390×844，第一列是〈主題〉，摺線落在〈行距〉附近）。

這是知道了才做的，不是做完才發現：

- **書該露出來的那塊還在。** 面板站在 576px 的上限，書留 268px，佔 32%，`hand-held.spec.ts` 那條
  「至少三分之一」照樣過。那是 #160 當初真正要保住的東西。
- **「六列不用捲」那條保證撤掉。** 它本來就只在繁體中文底下成立：英文比中文寬（「無 小 中 大」
  對上 None/Small/Medium/Large），37px 早就在摺線下了，那是 #27。所以撤掉的是一條**只有一種語言
  算數**的保證，`hand-held.spec.ts` 裡那條 zh-TW 專用的測試跟著刪掉。
- **stepper 省的不是高度。** 量過：全部用磚是 224px 在摺線下，改成刻度用 stepper 是 205px，只差
  19px。留白與行距用 stepper 的理由是上面第二條（四張分不太出來的圖 vs 兩顆講得出順序的鈕），
  不是省空間。

還有一個施工中才看得到的：**面板一旦會捲，`.panel-body` 這個 flex 直欄就會把沒有內容的固定高度
元素壓扁**。自帶字型那條 3px 的下載進度條被壓成 0px，是 `draggable.spec.ts` 抓到的。修法是給它
`flex: none`。

## 沒有選的路

- **在〈設定〉裡放一段假的示範文字當預覽。** 那是加東西不是拿掉，而且假文字排起來跟真的書不一樣，
  給的是錯的印象。
- **〈主題〉不進 tab，固定在分頁列上方永遠可見。** 效果最好（在〈帳號〉頁按深色也是整頁換色），
  但一個不屬於任何 tab 的控制項在結構上是特例，換到的只是少一次點擊。
- **〈設定〉不要 tab，改成一頁到底的區段清單。** 現在剛好，但〈帳號〉之後還會長出付款與備份，
  那時候得把 tab 加回來。
- **兩個殼用兩種版面**（設定畫面標籤在上、閱讀面板標籤在左）。那是把一個元件變成兩套版面，正是
  ADR-0005 收掉的那種東西。
