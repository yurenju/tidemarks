# 收費的界線是每個月的帳單

日期：2026-08-04。

## 決定

**不註冊完全免費，而且功能完整**：匯入、閱讀、直排、highlight、筆記、統計、匯出，全部在
使用者的瀏覽器裡跑完。

**註冊要收費**，一個級距，不分級。註冊換到的是同步與 MCP。

怎麼分：**這個功能會不會長出每個月的帳單。** 不是「這個功能值多少錢」，也不是「這個功能難
不難做」。

## 為什麼這樣分

它是**成本結構的形狀**，不是拍腦袋：本機閱讀跑在使用者的瀏覽器裡（維護者零成本），同步與
MCP 跑在 Worker + D1 + R2 上（按量付費）。

這種定價站得住，因為使用者問「為什麼要收錢」的時候答得出來。

## MCP 不能單獨賣

它不是加值功能。MCP 的取節與搜尋要 Worker 自己 parse epub——**它就是那個逼伺服器看得懂
使用者的書的功能**（見 [ADR-0009](0009-open-source-buys-an-exit-not-contributions.md)）。
而且它跟同步共用同一份資料，邊際成本幾乎不增加。成本沒差，分級就只是為了多賺錢製造的
複雜度。

一個人維護，多一個方案就多一組結帳狀態、多一組權限判斷、多一份要維護的說明。而 MCP 是這個
產品最特別的東西，藏在高階方案裡等於自廢武功。

## 價格不照成本訂

量到的數字（2026-08，Cloudflare 官方價目表）：

| | |
| --- | --- |
| Workers Paid | $5/月，含 1000 萬 requests、3000 萬 CPU-ms |
| R2 儲存 | $0.015/GB/月，**免費額度 10GB/月** |
| R2 對外流量 | **$0** |
| D1（Paid） | 含 250 億 rows read、5000 萬 rows write、5GB |

一個典型使用者（50 本、150MB）一年的邊際成本**不到 US$0.05**。年費抓 NT$800 的話，**三個
付費使用者就打平整年的 Cloudflare 帳單**。

所以照成本訂會訂出一年台幣一百塊，而那個價格會殺死這門生意——不是因為賺不夠，是因為
**它直接攻擊開源要買的那個東西**。使用者要把整櫃書搬進來之前，心裡問的是「這東西五年後
還在嗎」。太便宜的價格回答「不在，這是副業，作者膩了就關」。

價格對照的是**一本書的錢**：一年不到一本書，換所有的書在所有裝置上都在。使用者算得出來，
而且這個對照會跟著書價一起通膨，將來要調價有現成的說法。

實際數字未定。

## 唯一會長大的成本：CPU

MCP 的取節與搜尋要真的 parse epub、算 CFI，那是 CPU time——超過 3000 萬 CPU-ms 之後
$0.02/百萬 ms。

所以 [spec](../specs/mcp/spec.md) 裡那份「匯入時預建的純文字 ↔ CFI 對照表」有第二個
身分：**它不只是效能優化，是唯一的成本控制閥**。順序不變——它是快取，不是第二份真相。

## 不做時間制試用，做無條件退款

**免費層就是試用，而且沒有到期日。** 使用者可以用一個月確定自己喜歡這個閱讀器，才決定要
不要買同步。他唯一沒試到的是同步，而同步會不會動**五分鐘就知道**——時間制試用要解決的
問題，在這裡不存在。

所以改成 **14 天無條件退款**。

綁卡試用（Stripe 的 `trial_period_days`）工一樣少，轉換率明顯較高，但**忘了取消被扣款是
網路上最被討厭的模式之一**。spine 整個產品的定位是信任——local-first、開源、不續訂也不刪
你的書——**在收錢的那一步用一個被討厭的模式，會讓前面全部失效**。這是這個產品特有的取捨，
不是通則。

## 停止付費之後不刪東西

帳號留著、資料留著，同步與 MCP 停掉。**保留 24 個月**，到期前寄信通知才清。

成本上這件事幾乎不存在：一個使用者留一年 US$0.03，三千個殭屍帳號一個月 US$7。

而因為 spine 是 local-first，停止付費的那一刻**書本來就還在使用者的裝置上**。所以留著
伺服器那一份，風險是零、成本是零，但可以大聲講出來：

> 你不續訂，我不刪你的東西。同步會停，書和筆記留在原地，你隨時可以匯出，也隨時可以回來。

那句話是開源買不到的另一半：開源證明「你收掉了我架得起來」，這句話證明「你還在，但我不付
了，你也不會扣我的書」。反面很醜——「不付錢就刪你的書」是那種會被截圖轉發的事，一個人扛
不起。

24 個月這個數字的用意是**比任何人「我明年再回來」的時間長**。有上限是為了將來真的需要清
的時候不必食言；寄信通知是為了那一天不會有人覺得被偷襲。

**匯出永遠不鎖在付費牆後面。** 一個不能把資料拿走的服務，前面所有的信任建設都白做。
