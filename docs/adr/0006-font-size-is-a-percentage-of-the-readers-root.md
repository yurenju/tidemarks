# 字級是讀者 root 字級的百分比，不是絕對 px

日期：2026-07-31。

取代 [ADR-0003](0003-epub-ts-to-frond.md) 裡「`settings.fontSize` 從百分比改成 px」那一項。

## 決定

`ReaderSettings.fontSize` 存的是**百分比**，分母是**讀者自己瀏覽器的 root 字級**
（`getComputedStyle(document.documentElement).fontSize`）。範圍 80–200，每格 5，預設 115。

換算只發生在一個地方：`frondSettings()` 把百分比乘上 `RenderContext.rootFontSize`，得到 frond
要的 px。分母怎麼來的在 `readRootFontSize()`，跟換算分開，所以 `frondSettings()` 仍然是純函式。

## 為什麼

spine 自己的介面全部用 `rem`，從來沒設過 root 字級，所以**介面一直跟著讀者的瀏覽器設定走**。
只有書的內文不跟——它拿到的是寫死的 px。一個把瀏覽器預設字級調到 20px 的人（多半是因為看不清楚），
在 spine 裡會看到放大的書架、放大的面板，翻開書卻回到 18px。這是唯一真正的缺陷，其他都是換標籤。

換句話說，這件事不是「px 難懂、百分比好懂」，是**書應該聽讀者已經講過的話**。

## 為什麼分母是讀者的 root，而不是 16 或書自己的字級

**不是固定的 16**：那樣百分比就只是 px 除以 16，讀者調瀏覽器字級一樣沒有用，等於什麼都沒改。

**不是書自己的字級**：frond 刻意把書的絕對字級 relativise 成 rem（`css.ts` 的
`relativiseFontSizes`，除數固定 16），就是為了把基準交到讀者手上，同時保住書自己的大小層級
（標題比內文大）。要它再吐回「這本書本文原本多大」，等於推翻那個設計；而且照 frond 的邊界規則
（`CLAUDE.md`〈frond 的邊界〉），這裡痛的不是「拿不到只有 frond 知道的事實」，是**乘法要有分母**
——那是 spine 自己的事。

順帶一提，百分比本來就是這套機制的原生講法：frond 收的那個 px 是「1rem 等於多少」，`px ÷ 16` 就是
比例。舊的 18px 寫成百分比是 112.5%，這種不上不下的數字正說明 px 是轉換過的中間產物。

## 三套詞彙，兩個範圍

存過的值有三種：epub.js 時代的百分比（70–200）、frond 時代的 px（14–32）、現在的百分比（80–200）。
`validFontSize()` 靠範圍分辨——px 頂到 32，百分比從 70 起跳，兩邊不重疊，所以**一個數字自己說得出
它是哪一套**。

- **px** 除以 16 換成百分比。16 是 frond 當初拿來解讀那些 px 的基準——那個 root 是 spine 絕對地設下去
  的，跟讀者的瀏覽器設定無關，所以除數是 16 而不是讀者現在的 root。
- **舊百分比不用換**。epub.js 的百分比也是相對瀏覽器預設，差別只在分母現在會跟著讀者跑。
- 兩者都**吸附到 5 的格子上再夾進 80–200**。夾而不是丟：70% 一樣在說「比標準小」，落在最接近的一格
  保得住那個意思，退回預設就整個沒了。

預設取 115 而不是整數的 100，因為舊預設 18px 換算後是 112.5%，吸到格子上就是 115。這樣要解釋的數字
只有一個。

### 遷移之後大小會動多少

**沒調過瀏覽器字級的讀者（root 就是 16px）幾乎不動**：18px 變成 18.4px，差的是吸附到格子上那 2.5%。

**調大過瀏覽器字級的讀者會變大**，而且幅度不小：root 設 20px 的人，原本的 18px 會變成 115% × 20 =
23px。**這是這次改動的用意，不是副作用**——那個人早就講過「字要大一點」，只是書一直沒在聽。要說「遷移
不改變任何人看到的大小」就等於說這次什麼也沒做。

格子從 1px 一格（14–32px，19 段）換成 5% 一格（80–200%，25 段）。段數變多，每一段在 16px 的 root 上
約 0.8px，比原本的 1px 更細——讀者能停的位置沒有變少。

## 代價

- **debug 時要多一次心算。** ADR-0003 與瀏覽器測試原本都用 px 講話。願意付，因為換來的是讀者不必
  在兩個地方各講一次「我要大一點的字」。
- **讀者中途改瀏覽器字級不會即時生效。** 沒有事件可以聽，所以下一次動到設定或重開書才會反映。為這種
  很少發生的事掛一個 listener 划不來。
- **spine 哪天在 `:root` 設了字級，`readRootFontSize()` 就會不聲不響地變成在回答別的問題。** 這條寫在
  那個函式的註解裡。
